# Архив исходников CounterMine2

Каждая папка соответствует локальному снимку версии. В GitHub Releases опубликованы архивы основных выпусков. Беты, установщики и служебные материалы доступны в папках этого каталога.
Для 4.0–5.0 обновлённые исходники приложены к существующим релизам отдельным ZIP.
В архив включены лаунчеры, установщики, дополнительные пакеты, тест 3D и сайт.

## Сборка

Исторические снимки могут зависеть от внешних сервисов и отдельных пакетов ресурсов.
Большой внешний assets.zip, готовые сборки, локальные настройки IDE и журналы исключены.
Для интеграций Discord задайте переменные окружения, используемые в constants.py.
